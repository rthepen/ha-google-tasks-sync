# Home Assistant Add-on Repository: Google Tasks Multi-Sync

[![Home Assistant Badge](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Frthepen%2Fha-google-tasks-sync)

Dit is de officiële Home Assistant Add-on repository voor de **Google Tasks Multi-Account Sync Add-on**.

## 📦 Installatie in Home Assistant

1. Klik op de knop hierboven of voeg handmatig de repository URL toe:
   ```text
   https://github.com/rthepen/ha-google-tasks-sync
   ```
2. Ga in Home Assistant naar **Instellingen** -> **Add-ons** -> **Add-on Winkel**.
3. Klik rechtsboven op het menu (`⋮`) -> **Repositories**.
4. Plak de URL `https://github.com/rthepen/ha-google-tasks-sync` en klik op **Toevoegen**.
5. Vernieuw de pagina en installeer **Google Tasks Multi-Account Sync**.

## 🌟 Functies
- 🔄 Automatische 2-weg synchronisatie tussen meerdere Google Accounts (Roy & Karen).
- 📋 Ingebouwde Web UI (Ingress) met live JSON viewer & editor.
- 🚀 Direct kopiëren, downloaden, bewerken en toepassen van taken en lijsten als JSON.
